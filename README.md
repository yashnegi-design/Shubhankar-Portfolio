# Shubhankar Negi — Developer Portfolio

> Full Stack Developer at **Larsen & Toubro (L&T)**, Pune.

A high-performance, minimalist, architectural developer portfolio inspired by Swiss editorial design and wireframe engineering aesthetics. Engineered with pure vanilla HTML5, CSS3, and modern JavaScript with zero external framework overhead (99+ Lighthouse score).

---

## Live Architecture & Features

- **Compile Boot Screen:** Precision SVG monogram drawing animation with real-time kernel boot log telemetry and progress interpolation.
- **Topographic Contour Terrain Canvas:** Dynamic Marching Squares isoline elevation generator that deforms and elevates around cursor coordinates.
- **Crosshair Axis HUD:** Full-span horizontal and vertical viewport axes tracking pointer position with centered blue reticle and live `X · Y` coordinates.
- **Character Scramble / Hacker Decrypt:** Responsive kinetic text scrambling on headings, navigation links, and work items.
- **Selected Work (3-Stage Architectural Inspector):**
  - `01 Plot`: Wireframe blueprint specifications and latency tolerances.
  - `02 Build`: Microservice system structs and code architecture.
  - `03 Live`: Active interactive simulations (L&T HTTP/2 packet routing, OpenCV 4-stage filter studio, Desktop Voice Assistant waveform, and academic evaluation metrics).
- **Interactive REST Benchmark Probe:** Functional client simulation for querying `/api/v1/` endpoints with live latency metrics, status codes, and syntax-highlighted JSON responses.
- **Docked Developer REPL Terminal:** Interactive command-line dock (`shubhankar@pune-cluster:~`) supporting `whoami`, `lnt`, `status`, `skills`, `projects`, `matrix`, `theme`, and `help`.
- **Matrix Digital Rain Overlay:** Full-screen falling digital glyph stream.
- **Haptic Sound Synthesis:** Synthesized mechanical tactile click sound effects via the Web Audio API.
- **Blueprint Grid Mode [G]:** 32px architectural grid overlay with viewport dimension telemetry.
- **Quick Command Palette [⌘K]:** Fast keyboard navigation modal.

## Local Development

Run with any static web server:

```bash
# Python 3
python -m http.server 3000

# Or Node npx serve
npx serve .
```

Open `http://localhost:3000` in your browser.

---

## Deployment to GitHub Pages

1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`.
4. Click **Save**. Your portfolio will be live at `https://yashnegi-design.github.io/Shubhankar-Portfolio/`.
